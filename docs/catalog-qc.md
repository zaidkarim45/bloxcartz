# Catalog Quality Control

Generated by `scripts/run_qc.py` against `data/catalog.json` after crawl → price merge → rarity resolution → image download → image processing. Re-run that script any time the catalog changes; it overwrites `data/_qc_report.json` (gitignored — regenerate rather than trust a stale copy) and prints this same summary.

## How to re-run

```bash
python3 scripts/crawl_catalog.py        # structural crawl (curl-based)
python3 scripts/build_catalog.py        # merge with price/stock data
python3 scripts/resolve_rarity.py       # resolve rarity names from colors
python3 scripts/download_images.py      # download raw images
python3 scripts/process_images.py       # normalize/crop/pad
python3 scripts/generate_shopify_csv.py
python3 scripts/generate_image_map.py
python3 scripts/run_qc.py               # this report
```

## Checks performed

- Every product has a name, game, and Shopify handle
- No duplicate Shopify handles
- No unrecognized game slugs
- Every product has a downloaded raw asset on disk
- Every product has a processed (normalized) asset on disk
- No filename collisions inside `assets/catalog/raw/`
- Which products share a single source image with another product (informational, not necessarily an error — see below)
- Every image file actually opens as a valid image (PIL `.verify()`)
- Rarity name coverage (unambiguous vs. ambiguous — see `docs/catalog-audit.md`)
- Product counts by game and by category
- Availability (in stock / out of stock) counts

### Missing products

None — every category page Phase 0 confirmed exists was crawled, and every category's product count matches the live filter-sidebar counts exactly (verified during the crawl, see `docs/catalog-audit.md`).

### Missing images

None — all 296 source image URLs downloaded successfully (0 failures), and all 296 processed successfully (0 failures). All 296 raw + 296 processed files open as valid images (PIL `.verify()`), 0 broken.

### Duplicate products

None — 0 duplicate Shopify handles across 296 products.

### Products sharing a source image with another product

15 products across 6 shared images — all explained by the live site's own asset reuse, not a mapping error introduced during migration:
- Quantity-tier gear variants (e.g. Grow a Garden 2's 250x/500x/1000x Super Sprinklers) legitimately share one icon on bloxcart.com itself.
- One generic currency icon is shared between Pet Simulator 99's "1B Gems" and 99 Nights in the Forest's "100 Diamonds" — two unrelated games, same placeholder art on the source site.

Full list in `data/_qc_report.json` → `products_sharing_one_source_image` (gitignored — regenerate via `run_qc.py` to see it).

### Uncertain mappings

- **Rarity name**: 180 of 296 products (61%) have `rarity_ambiguous: true` in `data/catalog.json` — their accent-bar color is shared by two rarity names within that game, so the name could not be determined from the listing pages alone. See `docs/catalog-audit.md` for the full explanation and the per-game color legend. **These products got NO `rarity:` tag in `shopify-products.csv`** rather than a guessed one.
- **Bundle model**: only one bundle product exists in the current live catalog (MM2's "Ocean Bundle"), confirmed to behave as a single SKU. This is a sample size of one — if BloxxCart plans more bundle products than currently exist on BloxCart, confirm the single-SKU model still fits the intended use case.

### Licensing / source concerns

See `docs/catalog-audit.md` → "Critical finding" section. Summary: images are the merchant's own already-live Shopify-hosted assets (safe to migrate between the merchant's own stores), but the underlying item artwork depicts third-party Roblox game IP that BloxCart itself disclaims ownership of and uses under an identification/resale rationale. Flagged for the merchant's own legal judgment, not resolved here.

### Data that needs manual confirmation

1. **Product descriptions** — not captured for 295 of 296 products (see `docs/catalog-audit.md`). `Body (HTML)` is blank in the CSV.
2. **Real inventory quantities** — only binary availability is public; CSV uses placeholder quantities (10 / 0).
3. **Ambiguous rarity names** — 180 products, listed above.
4. **Game card gradient colors** in `templates/index.json` / `templates/list-collections.json` — these were set from the Phase 0 screenshot description (reasonable per-game color choices) rather than pixel-sampled from the live site's actual CSS. Real game thumbnail/icon artwork (`assets/catalog/games/`) was downloaded and is accurate; the CSS gradient behind it in the theme is still an approximation.
